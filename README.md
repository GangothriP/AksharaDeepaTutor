# Akshara-Deepa Tutor

Akshara-Deepa Tutor is a modern offline self-study Android application developed for 10th standard students to support effective learning, syllabus tracking, quiz-based self-assessment, and academic performance analysis. The application provides an organized digital learning environment where students can access study materials, monitor progress, identify weak subjects, and maintain daily study consistency without internet connectivity.

The project is developed using modern Android development technologies including Kotlin, Jetpack Compose, MVVM Architecture, Room Database, Hilt Dependency Injection, Coroutines, StateFlow, Navigation Component, and Material 3 design components.

---

## Key Features

- Secure user registration and login system
- Chapter-wise study notes for multiple subjects
- Timed MCQ quiz system with automatic score calculation
- Review answers module for mistake analysis
- Subject-wise syllabus progress tracking
- Strength Map for performance visualization
- Gap Analysis for weak subject identification
- Daily goals and streak tracking system
- Fully offline functionality using Room Database

## System Architecture

The application follows the MVVM (Model-View-ViewModel) architecture pattern to maintain scalability, maintainability, and separation of concerns.

### Architecture Layers
- Presentation Layer – Jetpack Compose UI Screens
- ViewModel Layer – Business logic and UI state management
- Repository Layer – Data communication handling
- Local Database Layer – Room Database storage

## Offline Functionality

All application data including:
- Student details
- Quiz questions
- Quiz scores
- Syllabus progress
- Daily goals

is stored locally using Room Database, enabling the application to function completely offline.
